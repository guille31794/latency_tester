Indicaciones de seguridad

  • No exponga el equipo a líquidos ni temperaturas superiores a 40 °C.
  • No dirija el LED a los ojos.
  • Use únicamente la batería y cargador especificados (5 V / 3 A).
  • No abra la carcasa con el equipo conectado a corriente.
  • Ante calentamiento excesivo u olor a quemado, desconecte inmediatamente.

Descripción del equipo

El medidor emite un pulso luminoso (LED) hacia la cámara del sistema bajo prueba. Un fotosensor detecta cuándo el monitor reproduce ese estímulo. La diferencia temporal es la latencia del sistema.

Componentes

  • Pantalla táctil (frontal): 7 pulgadas, capacitiva. Único medio de interacción.
  • LED estimulador (lateral): se enciende automáticamente durante las mediciones.
  • Fotosensor (lateral opuesto): debe orientarse hacia el monitor.
  • Puerto USB-C (inferior): carga y alimentación.

Encendido y apagado

  • Encender: mantenga pulsado el botón de encendido 2 segundos.
  • Apagar: mantenga pulsado el botón ← en la pantalla de inicio durante 3 segundos.

No desconecte la alimentación de forma abrupta para no dañar las mediciones guardadas.

Pantalla de inicio

El menú principal presenta cuatro opciones:

  • Comenzar medición: accede a la pantalla de mediciones.
  • Historial de mediciones: consulta mediciones anteriores.
  • Ajustes: configura idioma, fuente y modos visuales.
  • Ayuda: muestra este manual e información general.

Todas las pantallas tienen un botón amarillo ← para volver atrás.

Toma de mediciones

1. Calibración (obligatoria antes de medir)

  1. Oriente el fotosensor hacia la zona del monitor donde aparecerá el estímulo.
  2. Pulse Calibrar.
  3. El LED parpadeará durante el proceso (4 ciclos). No mueva el equipo.
  4. Resultado: verde = éxito, rojo = fallo (reoriente el sensor).

2. Configurar parámetros

  • Intervalo entre mediciones: 100–2000 ms. Valores bajos = más datos.
  • Duración: 10–600 s. Tiempo total del ensayo.

3. Medir

  1. Dirija el LED hacia la cámara y el fotosensor hacia el monitor.
  2. Pulse Comenzar.
  3. El botón parpadea en verde mientras mide.
  4. Al terminar: verde = éxito (se muestra la gráfica), rojo = error.
  5. Los resultados se guardan automáticamente.

Pulse Detener en cualquier momento para cancelar.

Interpretación de la gráfica

  • Eje horizontal: tiempo transcurrido (s).
  • Eje vertical: latencia medida (ms).
  • Cada punto es una medición individual.

Historial de mediciones

Lista todas las mediciones almacenadas. Acciones disponibles:

  • Comprobar: ver gráfica y datos (nombre, fecha, latencia media, intervalo).
  • Borrar: elimina permanentemente la medición seleccionada.
  • Renombrar: cambia el nombre del fichero de medición.

Ajustes

  • Idioma: Español, English, Polski.
  • Tamaño de fuente: 9–15 pt.
  • Modo daltónicos: paleta de alto contraste.
  • Modo nocturno: tema oscuro para baja iluminación.

Pulse Aplicar para guardar. Cancelar para descartar.

Ambos modos pueden activarse simultáneamente. El modo daltónico tiene prioridad visual.
